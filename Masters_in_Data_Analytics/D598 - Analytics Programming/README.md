# Analytics Programming

## Course Overview

Analytics Programming builds algorithmic thinking skills through hands-on practice in Python and/or R (I selected Python). The course introduces core programming concepts and progressively develops the ability to apply them in real-world analytics tasks. Learners gain experience with data acquisition, organization, and manipulation using common libraries and packages, while also exploring methods for applying statistical functions and building graphical representations to present insights.

This foundation prepares learners to approach analytics problems with structured problem-solving techniques and equips them with versatile tools for handling data.
## Key Learnings

Through this course and its programming tasks, I gained experience in:

- Programming Foundations
Applied syntax, control elements (loops, conditionals), and modular components (functions, reusable code) in both Python and R.

- Data Acquisition & Organization
Used programming to load, clean, and structure datasets from various sources, preparing them for analysis.

- Data Manipulation & Transformation
Leveraged libraries and packages to filter, sort, group, and reshape data for meaningful insights.

- Statistical Functions & Analysis
Implemented basic statistical methods to analyze datasets and validate findings.

- Data Visualization & Reporting
Created graphical outputs and structured presentations of results to communicate analytical insights effectively.

- Documentation & Best Practices
Documented complex programming tasks clearly, ensuring readability and reproducibility of work.
