# Masters in Data Analytics – Data Engineering Portfolio

This repository contains my coursework, projects, and portfolio artifacts from the **Master of Science in Data Analytics – Data Engineering**.  

The goal of this repo is to showcase my progression as a data professional and provide a collection of real-world projects that demonstrate my skills in **data modeling, database design, data engineering, and analytics**.

---

## 📂 Repository Structure

- **D596–D610** → Course-specific folders containing pseudocode, SQL scripts, Python, ERDs, and analysis deliverables.  
- **ERDs/** → Entity-relationship diagrams for relational database designs.  
- **SQL/** → Queries and scripts for relational and analytical databases.  
- **NoSQL/** → MongoDB schema design and queries.  
- **Docs/** → Written reports, pseudocode, and academic papers.  

Each course folder includes:
- My submission (code, diagrams, documentation)  
- Any supporting documentation I can provide  

---

## 🛠️ Skills & Tools Demonstrated

- **Programming & Scripting:** Python (Pandas, NumPy, Matplotlib), SQL (PostgreSQL, Oracle, MySQL), MongoDB  
- **Data Modeling:** ERDs, star and snowflake schemas, indexing strategies  
- **Analytics & Visualization:** Jupyter Notebooks  
- **Version Control & Collaboration:** Git, GitHub, documentation best practices  

---

## 🚀 How to Use This Repo

- Navigate by course folder to explore specific tasks.  
- SQL files can be run in PostgreSQL or Oracle DB environments.  
- Documentation (pseudocode, reports) is provided in Markdown/PDF format.
