# Analyst Builder Projects Portfolio

## Overview
This repository contains a collection of **data analysis and data engineering projects** completed as part of my professional development and coursework in the **WGU MSDA – Data Engineering track**.  

Each project is designed to build and demonstrate practical skills in **SQL, data cleaning, data modeling, and analytics**. Together, they showcase my ability to take raw data, transform it, and prepare it for meaningful insights.

## 📂 Project List

### [Project 1: World Life Expectancy – Data Cleaning](./MySQL%20for%20Data%20Analytics/Project%201%20World%20Life%20Expectancy%20-%20Data%20Cleaning.md)
- **Goal:** Clean and prepare the World Life Expectancy dataset for analysis.  
- **Highlights:**  
  - Removed duplicate country-year records using composite keys  
  - Imputed missing `Status` values with self-joins  
  - Filled missing `Life Expectancy` values using temporal averages  
- **Skills:** SQL joins, data imputation, quality assurance
